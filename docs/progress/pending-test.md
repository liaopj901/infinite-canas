# 待测试

- 登录页只显示账号密码登录/注册，不再显示 Linux.do 登录入口，标题和说明文案统一使用 qqliao画布品牌。
- 后台关闭“强制登录后使用”时，游客仍可进入画布、生图、视频、工作流、提示词和素材等页面，并使用本地直连能力。
- 后台开启“强制登录后使用”时，游客访问除首页和登录页之外的用户功能页面会跳转登录，并在登录成功后返回原目标页面。
- 后台开启“强制登录后使用”时，游客点击首页“开始使用”不会提前创建本地画布，而是先进入登录；“打开画布”同样先进入登录。
- 已登录用户不受“强制登录后使用”开关影响，仍可正常进入各功能页面；素材库继续保持始终要求登录。
- 管理后台同时关闭“云端渠道生成后自动同步”和“本地直连生成后自动同步”时，图片工作台、视频工作台和画布生成结果都不会自动上传。
- 仅开启“云端渠道生成后自动同步”时，云端渠道生成结果会自动上传，本地直连生成结果不会自动上传。
- 仅开启“本地直连生成后自动同步”时，本地直连生成结果会自动上传，云端渠道生成结果不会自动上传。
- 同时开启两个开关并配置可用云存储后，两种渠道的图片工作台、视频工作台和画布生成结果都会自动同步，且生成记录保留云端 `storageKey`。
- 生成任务开始后切换渠道模式，不会改变该任务完成后的自动上传策略。
- 自动同步失败时，图片、视频或画布生成仍保持成功，页面显示告警，之后仍可使用手动同步。
- 普通上传、参考素材和音频生成不受两个自动同步开关影响。
- `gpt-image-2-2k` 同时存在于启用渠道和后台“系统可用模型”时，可以在生图模型列表中选择，选择后不会回退到 `gpt-image-2`。
- 仅存在于渠道但未加入后台“系统可用模型”的模型不会出现在云端模型选择器中。
- 首页显示 qqliao画布 Logo 和“开始使用 / 打开画布 / 返回 NewAPI”三个入口，点击后分别创建并进入新画布、打开画布列表、跳转到 NewAPI 控制台。
- 首页底部固定显示项目来源、原作者和 AGPL-3.0 许可证声明，窄屏下允许自然换行且不遮挡主要内容。
- 顶部导航和其他用户可见品牌位置显示 qqliao画布，右上角不再显示 GitHub 图标。
- Windows 工作区构建 Docker 镜像时，入口脚本会转换为 Linux 换行，容器可正常启动并响应健康检查。
