# 待测试

- 登录页只显示账号密码登录/注册，不再显示 Linux.do 登录入口，标题和说明文案统一使用 qqliao画布品牌。
- 后台关闭“强制登录后使用”时，游客仍可进入画布、生图、视频、工作流、提示词和素材等页面，并使用本地直连能力。
- 后台开启“强制登录后使用”时，游客访问除首页和登录页之外的用户功能页面会跳转登录，并在登录成功后返回原目标页面。
- 后台开启“强制登录后使用”时，游客点击首页“开始使用”不会提前创建本地画布，而是先进入登录；“打开画布”同样先进入登录。
- 已登录用户不受“强制登录后使用”开关影响，仍可正常进入各功能页面；素材库继续保持始终要求登录。
- 管理后台同时关闭“云端渠道生成后自动同步”和“本地直连生成后自动同步”时，图片工作台、视频工作台和画布生成结果都不会自动上传。
- 仅开启“云端渠道生成后自动同步”时，云端渠道生成结果会自动上传，本地直连生成结果不会自动上传。
- 仅开启“本地直连生成后自动同步”时，本地直连生成结果会自动上传，云端渠道生成结果不会自动上传。
- 同时开启两个开关并配置可用云存储后，两种渠道的图片工作台、视频工作台和画布生成结果都会自动同步，且生成记录保留云端 `storageKey`。
- 生成任务开始后切换渠道模式，不会改变该任务完成后的自动上传策略。
- 自动同步失败时，图片、视频或画布生成仍保持成功，页面显示告警，之后仍可使用手动同步。
- 普通上传、参考素材和音频生成不受两个自动同步开关影响。
- `gpt-image-2-2k` 同时存在于启用渠道和后台“系统可用模型”时，可以在生图模型列表中选择，选择后不会回退到 `gpt-image-2`。
- 仅存在于渠道但未加入后台“系统可用模型”的模型不会出现在云端模型选择器中。
- 首页显示 qqliao画布 Logo 和“开始使用 / 打开画布 / 返回 NewAPI”三个入口，点击后分别创建并进入新画布、打开画布列表、跳转到 NewAPI 控制台。
- 首页底部固定显示项目来源、原作者和 AGPL-3.0 许可证声明，窄屏下允许自然换行且不遮挡主要内容。
- 顶部导航和其他用户可见品牌位置显示 qqliao画布，右上角不再显示 GitHub 图标。
- Windows 工作区构建 Docker 镜像时，入口脚本会转换为 Linux 换行，容器可正常启动并响应健康检查。
- 本地直连拉取模型列表时使用当前渠道的 Base URL 和 API Key，并忽略配置首尾空白；上游返回结构化错误或异常响应时显示具体原因。
- 图片工作台、画布云端任务和本地直连图片生成遇到网络异常或无明确业务错误的 `500/502/503/504` 时，首次失败后最多自动重试 3 次。
- 图片上游返回 `error.message`、`msg`、`message`、任务失败信息或任意 `4xx` 时直接显示原始错误，不自动重试。
- KIE/APIMart 图片任务创建成功后，轮询临时失败只重试当前查询，不重复创建任务；文本、视频和音频请求不受图片重试规则影响。
- Grok 文生图只展示并提交上游支持的 `1:1`、`3:2`、`2:3`、`16:9`、`9:16` 比例，旧尺寸会归一化到最接近的合法比例；KIE Grok 图生图不再显示无效尺寸设置，GPT 生图比例行为保持不变。
- 历史画布中的 base64 图片恢复只创建本地缓存，不会在页面打开时重复创建云端对象。
- 历史素材恢复只创建本地缓存，并保存本地 `storageKey`，重复打开页面不会重复上传。
- 账号 A 与账号 B 的画布、素材、图片历史、图片分类、视频历史和视频分类互不可见，退出登录后的游客数据也保持独立。
- 账号 A 切换到账号 B 的过程中，旧账号的延迟保存、轮询、自动同步和上传完成回调不会写入账号 B 的本地或云端数据。
- 旧账号任务完成时不会使用新账号 token 上传图片或视频；切换账号后正在同步的图片/视频状态不会污染新账号页面。
- 私有云端文件元数据和内容接口要求登录并校验 `StorageObject.CreatedBy`，账号 B 使用账号 A 的 `server:<id>` 不能读取 A 的文件。
- 私有云端媒体由前端携带当前账号 token 获取后转换为 Blob URL，图片和视频标签不会直接请求不带 Authorization 的私有文件地址。
- 用户自定义 S3/R2/WebDAV 配置按账号保存，账号切换不会复用其他账号的本地存储凭据。
- 本地文件清理暂时保持禁用全局扫描，避免因本地文件缺少 owner 索引而误删其他账号的文件；孤儿本地文件允许暂留。
- 云端媒体上传、删除和解析过程中切换账号时，继续使用调用时账号的 token、owner 和用户存储配置，不会把旧账号请求提交到新账号的存储配置。
- 生成图片先保存到 `.env` 配置的服务器本地目录；开启自动上传时云端成功后删除本地副本，未开启时可从图片工作台手动上传。
- `GET /api/v1/generation-logs/images` 只返回精简历史数据，图片按云端优先、本地其次展示；本地文件超过保留期后显示“图片已被清理”。

- 图片工作台的单张生成任务支持“取消生成”；批量生成时取消一张不会影响其余任务。
- 本地直连图片任务取消后会中止请求、流式读取和重试等待，且不会保存失败日志或弹出“生成失败”。
- 后端异步图片任务取消后会停止页面轮询、删除任务与生成中日志、跳过失败调用日志，并尽快断开服务端正在等待的上游请求；第三方未提供取消 API 时，不保证停止其内部计算或计费。
- 前端直连工作流尚未接入独立取消控制器，其生成中卡片不显示无效的取消按钮。
- 图片工作台批量删除完成后，确认弹窗会自动关闭并清空已选记录，不会因后续历史刷新失败而重复提交删除。
- 上传参考图使用私有云端存储时，页面以 Blob URL 预览；提交生成时私有 `/api/files/:id/content` 地址不会被当作公开 URL 交给上游，而是携带登录令牌读取后转换为参考图数据，不再返回 401。
- 新生成图片的日期目录权限固定为 `0755`，最终图片文件权限固定为 `0644`，不再因进程 umask 变成 `0600`；配置目录不可写时页面会明确提示检查 `GENERATED_MEDIA_DIR` 和目录权限。
- Docker 启动时会创建生成图片目录，并修复旧版本遗留文件的读取权限；本地图片内容读取失败时接口返回非 2xx，不会再被前端误当成图片 Blob。
